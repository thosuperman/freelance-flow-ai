# Judge credentials (template)

Copy this file to `submission/JUDGE_CREDENTIALS.md` (git-ignored) and fill it in. **Never commit the filled-in file or paste these passwords into the public Devpost description.** Put them only in a field that the form shows to judges and organizers, or in the testing-instructions field the rules describe.
