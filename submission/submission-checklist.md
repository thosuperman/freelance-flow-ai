# Devpost submission checklist

Official page: https://paypalaihackathon.devpost.com/. Re-read the official rules there before submitting; we could not fetch the rules page automatically.
Known from PayPal's developer blog: the project must "meaningfully use both PayPal and AI". Submissions close **12 Nov 2026** (confirm the exact time and time zone on Devpost). Winners are announced 21 Dec 2026.

- [ ] Project name, tagline (`project-tagline.md`)
- [ ] Description (`devpost-description.md`), in English
- [ ] "Built with" tags (`technologies-used.md`)
- [ ] Demo video (about 3 min, see `demo-script.md` / `video-storyboard.md`), uploaded publicly (YouTube/Vimeo), link tested logged-out
- [ ] Screenshots (`screenshot-checklist.md`)
- [ ] Public repository URL (license chosen; README up to date); confirm no secrets in history
- [ ] Live demo URL tested in a private window (`/demo` works; Sandbox buyer instructions included)
- [ ] Sandbox test buyer instructions for judges (e.g. "use your own PayPal Sandbox personal account", or provide a dedicated **sandbox-only** buyer)
- [ ] Every link in the submission opens (broken links can disqualify)
- [ ] Choose the prize categories that apply (e.g. Best Use of PayPal + AI)
- [ ] Team members added on Devpost
- [ ] Submit before the deadline, then re-open the submission page to confirm it shows as submitted
